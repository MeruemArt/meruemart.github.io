CWC - Instalación en Arquitectura Serverless

Introducción

Este artículo aplica para la arquitectura Serverless (nube)

A continuación, se detallan los dos métodos principales para la instalación del CWC en la arquitectura serverless:

1. Instalación vía Instalador

Proceso de instalación mediante instalador

  1. Prerrequisitos:

    • Obtener instalador y archivo war

    • Ruta COBIS_HOME_WEB

    • Configurar Apache Tomcat

  2. Una vez revisados los prerrequisitos se procede a ejecutar el instalador. En la arquitectura serverless es importante aclarar que el instalador CWC se puede ejecutar de 2 formas diferentes:

    • Instalador modo gráfico A. Serverless

    • Instalador modo consola A. Serverless

  3. Sistema de archivos del CWC

  4. Después de ejecutar el instalador se procede a levantar el contenedor. Para ello se requiere seguir con los siguientes documentos:

    • Licencia

    • Variable de ambiente

    • Levantar el contenedor CWC
